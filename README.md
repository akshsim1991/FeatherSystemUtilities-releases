# Feather System Utilities

Clean, speed up and maintain Windows: junk and Windows Update cache cleaning, deep scan, registry cleaning, program uninstaller with leftover removal, startup and services manager, duplicate / large file / empty folder finders. Everything runs on your own device: no account, no cloud service, no tracking.

**Version 2.0.1**

- Windows 7 SP1, 8.1, 10 and 11 (64-bit and 32-bit): [FeatherSystemUtilities-Setup-2.0.1.exe](https://raw.githubusercontent.com/akshsim1991/FeatherSystemUtilities-releases/main/FeatherSystemUtilities-Setup-2.0.1.exe)

Installed copies find new versions themselves (More > Check for updates, and automatically once a day if enabled in Settings) and ask whether to update now or later. The installer is checked against the SHA-256 in latest.json before it runs.
